# Journal de voyage familial

Application Streamlit permettant de partager un journal intime ou album de voyage avec la famille. Les images sont optimisées côté application avant d'être stockées dans Supabase Storage.

## Installation et lancement

Depuis le dossier `app_journey` :

```bash
python -m venv .venv
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Copiez ensuite le modèle de secrets et remplacez les valeurs factices par celles de votre projet Supabase :

```powershell
Copy-Item .streamlit\secrets.toml.example .streamlit\secrets.toml
```

> Pour des raisons de sécurité, le fichier `.streamlit/secrets.toml` est ignoré par Git. Créez-le directement avec les trois variables `SUPABASE_URL`, `SUPABASE_KEY` et `ADMIN_PASSWORD` si vous n'utilisez pas de modèle.

## Configuration Supabase

1. Créez un bucket **public** nommé `album-photos` dans **Storage**.
2. Dans l'éditeur SQL de Supabase, exécutez :

```sql
create table public.photos (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  title text not null,
  category text not null,
  image_url text not null,
  location text,
  latitude double precision,
  longitude double precision,
  profile text not null check (profile in ('thibaut', 'clara')),
  date_start timestamptz,
  date_end timestamptz,
  preview_img text,
  content text,
  emoji text
);

alter table public.photos enable row level security;

create policy "Les visiteurs peuvent lire les photos"
on public.photos for select
to anon
using (true);

create policy "Les visiteurs peuvent ajouter des photos"
on public.photos for insert
to anon
with check (true);

create policy "Les visiteurs peuvent supprimer des photos"
on public.photos for delete
to anon
using (true);

create policy "Les visiteurs peuvent téléverser dans l'album"
on storage.objects for insert
to anon
with check (bucket_id = 'album-photos');

create policy "Les visiteurs peuvent lire les métadonnées de l'album"
on storage.objects for select
to anon
using (bucket_id = 'album-photos');

create policy "Les visiteurs peuvent supprimer des images de l'album"
on storage.objects for delete
to anon
using (bucket_id = 'album-photos');
```

`image_url` contient un tableau JSON d’URL (une par photo). `preview_img` contient l’URL de l’image unique affichée sur la carte.

Si la table existe déjà, ajoutez la colonne avant de lancer la nouvelle version :

```sql
alter table public.photos
add column profile text not null default 'thibaut'
check (profile in ('thibaut', 'clara'));

alter table public.photos
add column if not exists latitude double precision,
add column if not exists longitude double precision;
```

La page Carte lit les coordonnées de la table `photos`. Le champ de lieu de l’Espace Admin propose une autocomplétion Photon fondée sur les données OpenStreetMap; la sélection enregistre son libellé, sa latitude et sa longitude. Le service public Nominatim n’est pas utilisé pour l’autocomplétion, car sa politique l’interdit.

Pour une application exposée publiquement, remplacez la clé anonyme et ces politiques d'écriture par une authentification Supabase adaptée : le mot de passe Streamlit seul ne constitue pas une barrière API.
